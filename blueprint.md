
# Lotto Drawing Website Blueprint

## Overview

A simple, visually appealing web application to simulate a lottery drawing. The application will generate and display a set of random lottery numbers with the click of a button. It will be built using modern web standards (HTML, CSS, and JavaScript) and will feature a clean, responsive design.

## Project Outline

*   **HTML (`index.html`):** The main structure of the application, including a title, a container for the lottery numbers, a button to initiate the drawing, and an area to display the results.
*   **CSS (`style.css`):** Styles for the application, ensuring a modern and visually appealing design. This includes layout, colors, fonts, and animations to enhance the user experience.
*   **JavaScript (`main.js`):** The logic for the lottery drawing. This includes generating unique random numbers and updating the UI to display them.

## Style and Design

*   **Layout:** A centered, clean layout using flexbox.
*   **Color Palette:** A modern color scheme with a dark background and vibrant colors for the numbers.
*   **Typography:** Clear, legible fonts.
*   **Animation:** Numbers will fade in and scale up for a dynamic effect.
*   **Icons:** Lottery-themed icons will be used to enhance the visual appeal.

## Features

*   **Lottery Number Generation:** Generate 6 unique random numbers between 1 and 45.
*   **Interactive Drawing:** A button to trigger the lottery number generation.
*   **Animated Results:** The generated numbers will be displayed with an animation.
*   **Responsive Design:** The application will be usable on different screen sizes.

## Current Plan

1.  **Modify `index.html`:** Update the title and set up the basic structure for the lottery drawing UI.
2.  **Modify `style.css`:** Add CSS to style the page, including a dark theme and styling for the lottery number containers.
3.  **Modify `main.js`:** Implement the JavaScript logic to generate and display the lottery numbers when the button is clicked.
